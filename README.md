# lol-blender
this is a plugin made for myself to automate physics for thing like hair in league of legends
also added tabs to import file and shit, load anm, go bind pose, idk made thing for me easier, also auto weight tabs crazy good
and for the physics I tried to improve it, added live preview, made it much faster, and improved collision, it spawn shape like box and sphere and you can show/hide them to move them and resize them, just edit the collision box how you want and pray 
just go use and pray idk
